# Java Sorting Algorithms

This repository contains Java implementations of four sorting techniques.

## Algorithms Covered
1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Built-in Sorting using Arrays.sort()

## Technologies
- Java
- VS Code

## Learning Objectives
- Understand how sorting algorithms work.
- Practise arrays and loops.
- Compare sorting algorithms.
- Understand time complexity.
